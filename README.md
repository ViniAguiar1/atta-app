# atta-app

Plataforma ATTA em Next.js + Supabase (painel da clínica, fluxo do paciente e migrations do banco).

Fluxo: branch `tipo/ENG-<n>-slug` a partir da `develop`, PR para a `develop` com CI verde, merge por rebase. A `main` só recebe release, pelo dono.

Dados: só fictícios. Nunca dado real de paciente, profissional ou clínica.
