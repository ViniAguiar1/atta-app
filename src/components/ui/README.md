# components/ui

Componentes compartilhados entre os grupos de rota (dono: Frontend). Ex.: `DataState`.

- `Subabas` (dono: Frontend 3): subabas de um módulo com sublinhado da ativa e `aria-current` (Pacientes, ATTA, Pasta).
- `CardDeResumo` (dono: Frontend 3): card de número com rótulo em versalete, ícone com tom (neutro, marca ou negativo), legenda, "—" sem número e filtro opcional com `aria-pressed` (Pacientes, ATTA, cards simples da Agenda).
